# OpenCV 多目标跟踪滤波器参数调节说明

## 1. 文档说明

六种模型均定义在 [`include/cerateEKF.hpp`](../include/cerateEKF.hpp)。构造函数的默认值以该头文件为准。[示例与封装接口](10-yolo-multi-object-tracking.md)

| 模型 | 状态维度 | 运动模型 |
|---|---:|---|
| CoordinatedTurnEKF5D | 5D | 恒角速度协调转弯 |
| CoordinatedTurnEKF6D | 6D | 可变角速度协调转弯 |
| GeneralMotionEKF6D | 6D | 通用非线性运动 |
| ConstantVelocityKF4D | 4D | 恒速度模型 |
| ConstantAccelerationKF6D | 6D | 恒加速度模型 |
| SingerKF6D | 6D | 衰减加速度模型 |

所有模型统一采用以下约定：

- 位置测量：二维坐标 `[x,y]`。
- 坐标单位：像素。
- 时间单位：frame。
- 默认 `dt=1.0`，表示相邻两帧之间的时间间隔。
- 测量来源：YOLO 检测框中心，或经过筛选的轮廓检测中心。

注意：各模型的 `q` 对应自己的噪声模型及离散化公式，切换滤波器后需以该模型的基准值重新定标。

## 2. 基础参数概念

在调整滤波器之前，需要理解三个主要概念。

### 2.1 测量噪声 R

R 表示滤波器对测量结果的不确定程度。

在当前项目中，主要对应 YOLO 检测框中心的抖动。

例如，目标实际中心是：

`(500, 300)`

但是 YOLO 每帧可能检测到：

- `(503, 299)`
- `(498, 304)`
- `(505, 301)`
- `(497, 298)`

这些偏差就是测量噪声。

R 越大，滤波器越不相信测量结果，更依赖运动模型。

R 越小，滤波器越相信测量结果，能够更快地跟随检测框变化，但也更容易受到检测抖动影响。

对于位置测量，通常使用：

$$
R=\begin{bmatrix}r&0\\0&r\end{bmatrix}
$$

这里需要区分两种参数形式：

- KF 中的 `r`：直接表示测量噪声方差。
- EKF 中的 `sigma_position`：表示测量噪声标准差，内部使用其平方构造 R。

例如：

如果测量中心的标准差约为 5 像素：

$$
r=5^2=25
$$

KF 使用 `r=25`，而 EKF 使用 `sigma_position=5`。

### 2.2 过程噪声 Q

Q 表示实际目标运动与滤波器运动模型之间可能存在的偏差。

例如：

滤波器假设目标保持匀速，但是实际目标突然加速，那么运动模型就会产生误差。

Q 越大，滤波器越允许实际运动偏离理论模型，能够更快适应运动变化。

Q 越小，滤波器越相信自己的运动模型，预测轨迹通常更加平滑，但可能产生滞后。

需要注意：

Q 不是简单地表示目标的实际加速度大小，而是描述模型没有准确描述的随机运动变化。

### 2.3 初始协方差 P0

部分 EKF 还会设置初始速度、角速度、加速度等状态的初始方差。

它与 Q、R 不同：

- Q：控制每次预测时增加多少过程不确定性。
- R：控制每次测量修正时相信测量的程度。
- P0：控制滤波器刚初始化时对初始状态有多大信心。

P0 越大，表示初始状态越不确定，滤波器更容易在开始阶段根据测量进行调整。

P0 越小，表示滤波器认为初始状态比较准确，不容易被初期测量改变。

## 3. CoordinatedTurnEKF5D

### 3.1 模型说明

状态向量：

$$
X=[x,y,v_x,v_y,\omega]^T
$$

其中：

- x、y：目标位置。
- vx、vy：目标速度。
- ω：目标角速度。

该模型采用协调转弯假设：

- 目标速度大小在短时间内近似不变。
- 目标以近似恒定角速度转弯。
- 角速度允许受到过程噪声影响。

适合速度变化不大、运动轨迹以转弯为主的目标。

### 3.2 需要调整的参数

构造函数：

```cpp
CoordinatedTurnEKF5D ekf(
    sigma_position,
    q_accel,
    q_alpha,
    init_velocity_var,
    init_omega_var
);
```

| 参数 | 默认值 | 含义 |
|---|---:|---|
| sigma_position | 5.0 | 位置测量标准差 |
| q_accel | 0.01 | 线性加速度过程噪声强度 |
| q_alpha | 0.00001 | 角速度随机游走的过程噪声强度 |
| init_velocity_var | 100.0 | 初始速度分量方差 |
| init_omega_var | 0.25 | 初始角速度方差 |

示例程序对前三项显式传入 `1.35, 0.90, 0.90`，可作为复现示例的起点。后两项使用构造默认值。

#### sigma_position

控制对 YOLO 检测中心的信任程度。

- 增大：更加相信运动模型，降低检测框抖动影响。
- 减小：更加相信 YOLO，滤波结果更贴近检测中心。

建议首先通过检测框中心的实际抖动估计该参数。

#### q_accel

控制目标线性速度变化的适应能力。

- 增大：更容易适应突然加速、减速。
- 减小：更倾向于保持原来的运动状态。

如果目标实际存在明显的加减速，但是滤波结果始终落后，可以尝试增大该参数。

如果滤波轨迹过于不稳定，可以尝试减小。

#### q_alpha

控制角速度变化的适应能力。

- 增大：更容易适应转弯速度的变化。
- 减小：更加相信角速度保持不变的假设。

如果目标转弯过程中角速度变化明显，而滤波器总是无法及时跟上，可以适当增大。

如果目标转弯轨迹出现不必要的摆动，可以适当减小。

此实现将 `q_alpha × dt` 加入角速度方差，5D 状态里的角运动量只有角速度。

### 3.3 调节建议

建议调节顺序：

1. 首先调整 sigma_position。
2. 再调整 q_accel。
3. 用转弯片段调整 q_alpha。
4. 如果刚开始几帧的速度或转向收敛偏慢，再检查两个初始方差。

如果目标主要是匀速转弯，优先保持较小的 q_alpha。

如果目标经常改变转弯速度，再逐渐增大 q_alpha。

## 4. CoordinatedTurnEKF6D

### 4.1 模型说明

状态向量：

$$
X=[x,y,v_x,v_y,\omega,\alpha]^T
$$

相比 5D 模型，增加了角加速度：

$$
\omega_{k+1}=\omega_k+\alpha_kdt
$$

$$
\alpha_{k+1}=\alpha_k
$$

它允许角速度随时间发生变化，因此能够描述比恒角速度模型更加复杂的转弯运动。

适合转弯速度不断变化的目标。

### 4.2 需要调整的参数

构造函数：

```cpp
CoordinatedTurnEKF6D ekf(
    sigma_position,
    q_accel,
    q_alpha,
    init_velocity_var,
    init_omega_var,
    init_alpha_var
);
```

| 参数 | 默认值 | 含义 |
|---|---:|---|
| sigma_position | 5.0 | 位置测量标准差 |
| q_accel | 0.01 | 线性加速度过程噪声强度 |
| q_alpha | 0.00001 | 同时作用于角速度与角加速度状态的过程噪声强度 |
| init_velocity_var | 100.0 | 初始速度方差 |
| init_omega_var | 0.35 | 初始角速度方差 |
| init_alpha_var | 0.01 | 初始角加速度方差 |

#### sigma_position

与 5D EKF 相同。

增大意味着更加相信模型，减小意味着更加相信 YOLO 测量。

#### q_accel

控制目标线性速度变化的适应能力。

增大后能够更快适应加速和减速，但也可能使预测轨迹更加不稳定。

#### q_alpha

这是 6D 模型中比较重要的参数。

它作用于角速度和角加速度组成的状态块。

- 增大：允许角速度和角加速度更加灵活地变化。
- 减小：更加相信当前角加速度状态，转弯变化更加平滑。

注意：5D 和 6D 的 q_alpha 虽然名称相同，但对应的噪声模型不同，不能直接沿用相同数值。

#### init_velocity_var

控制初始速度估计的不确定性。

- 增大：初始速度不可靠时，允许滤波器更快地根据后续测量修正速度。
- 减小：更加相信初始化时计算出来的速度。

#### init_omega_var

控制初始角速度的不确定性。

如果目标刚开始转弯时角速度估计不够准确，可以适当增大。

如果初始化时角速度估计比较可靠，可以减小。

#### init_alpha_var

控制初始角加速度的不确定性。

- 增大：允许初期角加速度根据后续观测进行较大调整。
- 减小：更加相信初始化得到的角加速度。

注意：三个 init 参数只影响初始协方差 P0，不是每一帧都会增加的过程噪声。

### 4.3 调节建议

建议顺序：

1. 调整 sigma_position。
2. 调整 q_accel。
3. 调整 q_alpha。
4. 最后调整三个初始方差。

如果目标开始转弯时预测偏差较大，先检查初始角速度和角加速度估计是否可靠，不要直接无限增大 q_alpha。

## 5. GeneralMotionEKF6D

### 5.1 模型说明

状态向量：

$$
X=[x,y,v,\theta,a,\omega]^T
$$

其中：

- x、y：位置。
- v：速度大小。
- θ：运动方向。
- a：切向加速度。
- ω：角速度。

与协调转弯模型不同，该模型使用运动方向和速度大小描述目标运动。

它允许目标速度大小和运动方向同时变化。

适合不一定保持圆周运动、也不一定保持恒定角速度的非线性运动目标。

### 5.2 需要调整的参数

构造函数：

```cpp
GeneralMotionEKF6D ekf(
    sigma_position,
    q_accel,
    q_omega,
    init_speed_var,
    init_heading_var,
    init_accel_var,
    init_omega_var
);
```

| 参数 | 默认值 | 含义 |
|---|---:|---|
| sigma_position | 5.0 | 位置测量标准差 |
| q_accel | 0.01 | 切向加速度过程噪声强度 |
| q_omega | 0.00001 | 角速度变化过程噪声强度 |
| init_speed_var | 100.0 | 初始速度方差 |
| init_heading_var | 0.25 | 初始运动方向方差 |
| init_accel_var | 1.0 | 初始加速度方差 |
| init_omega_var | 0.25 | 初始角速度方差 |

#### sigma_position

与其他 EKF 一样，控制位置测量噪声。

增大后更加相信运动模型，减小后更加相信检测中心。

#### q_accel

控制切向加速度的变化程度。

- 增大：更容易适应目标突然加速或减速。
- 减小：速度变化更加平滑。

如果目标在直线运动时经常加速，可以适当增大。

#### q_omega

控制运动方向变化的灵活程度。

- 增大：更容易适应突然改变运动方向。
- 减小：更加相信当前运动方向和角速度状态。

如果目标经常改变运动方向，但是滤波结果总是落后，可以适当增大。

#### init_speed_var

控制初始速度大小的不确定性。

初始速度估计不可靠时，可以增大。

#### init_heading_var

控制初始运动方向的不确定性。

如果目标刚创建时方向估计不稳定，可以适当增大。

#### init_accel_var

控制初始加速度的不确定性。

如果初始化时目标加速度估计不准确，可以增大。

#### init_omega_var

控制初始角速度的不确定性。

如果初始方向变化速度估计不准确，可以增大。

### 5.3 调节建议

建议顺序：

1. sigma_position。
2. q_accel。
3. q_omega。
4. 四个初始方差。

如果目标运动方向变化较快，但速度大小变化不大，优先考虑调整 q_omega，而不是 q_accel。

如果目标主要表现为加速和减速，则优先考虑 q_accel。

## 6. ConstantVelocityKF4D

### 6.1 模型说明

状态向量：

$$
X=[x,y,v_x,v_y]^T
$$

运动模型：

$$
x_{k+1}=x_k+v_xdt
$$

$$
y_{k+1}=y_k+v_ydt
$$

$$
v_{x,k+1}=v_{x,k}
$$

$$
v_{y,k+1}=v_{y,k}
$$

该模型假设目标保持恒定速度，加速度变化通过过程噪声描述。

它的优点是状态维度较低、运算简单，适合作为其他复杂模型的基准。

### 6.2 需要调整的参数

构造函数：

```cpp
ConstantVelocityKF4D kf(
    q,
    r
);
```

| 参数 | 默认值 | 含义 |
|---|---:|---|
| q | 1.0 | 白噪声加速度强度 |
| r | 25.0 | 位置测量噪声方差 |

#### q

控制实际运动偏离恒速度模型的程度。

- 增大：允许目标速度发生更明显的变化，响应更快。
- 减小：更加相信恒速度假设，轨迹更加平滑。

#### r

控制对 YOLO 测量的信任程度。

- 增大：更加相信恒速度预测。
- 减小：更加相信检测框中心。

### 6.3 调节建议

如果目标基本保持匀速：

可以尝试减小 q。

如果目标经常加速或减速：

可以尝试增大 q。

如果检测框抖动明显：

适当增大 r。

如果滤波框总是跟不上实际目标：

尝试减小 r 或增大 q。

注意：CV-KF 不估计加速度，`getAcceleration()` 返回零向量只是为了兼容统一接口，并不代表目标实际没有加速度。

## 7. ConstantAccelerationKF6D

### 7.1 模型说明

状态向量：

$$
X=[x,y,v_x,v_y,a_x,a_y]^T
$$

运动模型：

$$
x'=x+v_xdt+\frac12a_xdt^2
$$

$$
v_x'=v_x+a_xdt
$$

$$
a_x'=a_x
$$

Y 方向同理。

该模型假设短时间内加速度保持不变，但通过白噪声跃度模型允许加速度随时间发生变化。

相比 CV-KF，它增加了对加速度的显式估计。

### 7.2 需要调整的参数

构造函数：

```cpp
ConstantAccelerationKF6D kf(
    q,
    r
);
```

| 参数 | 默认值 | 含义 |
|---|---:|---|
| q | 1.0 | 白噪声跃度强度 |
| r | 25.0 | 位置测量噪声方差 |

#### q

控制加速度变化的随机程度。

- 增大：允许加速度更快发生变化。
- 减小：更加相信恒加速度模型。

如果目标加速度经常变化，但滤波结果总是滞后，可以适当增大 q。

如果目标运动较平稳，而预测轨迹出现不必要的变化，可以减小 q。

#### r

控制测量噪声。

增大后更加相信运动模型，减小后更加相信 YOLO。

### 7.3 调节建议

如果目标具有比较稳定的加速度：

优先尝试较小的 q。

如果目标经常突然改变加速度：

尝试增大 q。

如果目标实际运动较平稳，但检测框抖动严重：

适当增大 r。

注意：这个模型的 q 是白噪声跃度强度，与 CV-KF 中的白噪声加速度强度不是同一个物理量。

因此两个模型的 q 数值不能直接比较。

## 8. SingerKF6D

### 8.1 模型说明

状态向量：

$$
X=[x,y,v_x,v_y,a_x,a_y]^T
$$

Singer 模型与普通恒加速度模型最大的区别是：

普通恒加速度模型假设：

$$
a_{k+1}=a_k
$$

Singer 模型假设：

$$
\frac{da}{dt}=-\frac{1}{\tau}a+w(t)
$$

也就是说，加速度具有一定持续性，但是会随着时间逐渐衰减。

它既不像恒速度模型那样直接忽略加速度，也不像恒加速度模型那样认为加速度一直保持不变。

### 8.2 需要调整的参数

构造函数：

```cpp
SingerKF6D kf(
    q,
    r,
    tau
);
```

| 参数 | 默认值 | 含义 |
|---|---:|---|
| q | 1.0 | 加速度变化的白噪声驱动强度 |
| r | 25.0 | 位置测量噪声方差 |
| tau | 5.0 | 加速度衰减时间常数 |

#### q

控制加速度变化受到随机噪声影响的程度。

- 增大：允许加速度更加灵活地变化。
- 减小：加速度变化更加平滑。

#### r

控制对 YOLO 测量的信任程度。

- 增大：更加相信运动预测。
- 减小：更加相信检测结果。

#### tau

这是 Singer 模型最重要的特征参数。

tau 控制加速度能够持续多久。

- 增大 tau：加速度衰减更慢，更接近恒加速度模型。
- 减小 tau：加速度衰减更快，模型逐渐接近恒速度模型。

例如：

| tau | 运动特征 |
|---:|---|
| 2 | 加速度衰减较快 |
| 5 | 中等持续时间 |
| 10 | 加速度保持时间更长 |
| 20 | 更接近恒加速度模型 |

这些只是参数实验值，不代表不同 tau 对应固定的实际运动类型。

### 8.3 调节建议

如果目标突然加速后，加速度很快恢复正常：

尝试减小 tau。

如果目标持续加速一段时间，但是滤波器很快就认为加速度消失：

尝试增大 tau。

如果加速度变化太慢：

适当增大 q。

如果加速度估计过于不稳定：

适当减小 q。

建议先固定 q 和 r，单独调整 tau，观察目标加速后预测轨迹的变化，再调整 q。

## 9. 所有模型参数汇总

### 9.1 参数对照表

| 模型 | 位置测量参数 | 过程噪声参数 | 初始协方差参数 |
|---|---|---|---|
| CT-EKF5D | sigma_position | q_accel、q_alpha | init_velocity_var、init_omega_var |
| CT-EKF6D | sigma_position | q_accel、q_alpha | init_velocity_var、init_omega_var、init_alpha_var |
| GeneralMotionEKF6D | sigma_position | q_accel、q_omega | init_speed_var、init_heading_var、init_accel_var、init_omega_var |
| CV-KF4D | r | q | 无额外参数 |
| CA-KF6D | r | q | 无额外参数 |
| Singer-KF6D | r | q、tau | 无额外参数 |

### 9.2 不能直接比较的参数

以下参数名称相同或相似，但含义不完全相同：

1. CV-KF 的 q 与 CA-KF 的 q 不同。
2. CA-KF 的 q 与 Singer-KF 的 q 不同。
3. 5D EKF 的 q_alpha 与 6D EKF 的 q_alpha 不同。
4. 不同 EKF 中的 q_accel 可能对应不同状态模型和离散化方式。
5. KF 的 r 是位置方差，EKF 的 sigma_position 是位置标准差。

不要直接把一个模型的 q 参数复制到另一个模型中。

---

## 10. 实际调参流程

建议按照下面的顺序进行，不要同时调整所有参数。

### 第一步：确定测量噪声 R

在固定分辨率下收集一段静止目标的检测中心，或逐帧计算检测中心减去人工标注中心的残差。先排除明显错检，然后算出 x、y 残差的样本方差。代码对两轴共用一个参数，可用两轴方差均值作为 KF 的 `r`，其平方根作为 EKF 的 `sigma_position`。

例如，人工标注或通过稳定目标估计发现：

检测中心的标准差约为 5 像素。

那么：

$$
r=5^2=25,\quad R=25 I_2
$$

对应：

```cpp
// KF
r = 25.0;

// EKF
sigma_position = 5.0;
```

建议先固定 R，不要立即调整 q。

### 第二步：调整过程噪声 Q

保持 R 不变，逐步调整 q。

可以尝试：

```cpp
q = q_baseline * 0.1;
q = q_baseline * 1.0;
q = q_baseline * 10.0;
```

观察以下情况：

- q 太小：滤波轨迹平滑，但运动变化时容易滞后。
- q 合适：能够兼顾平滑性和运动响应。
- q 太大：滤波轨迹容易跟随检测噪声，预测不稳定。

注意：这是相对于当前模型基准参数的倍率实验，不是所有模型都通用的绝对数值范围。

### 第三步：单独调整 R

在 q 确定后，尝试以下 KF 方差倍率。EKF 若想对 R 使用相同倍率，应把 `sigma_position` 乘以倍率的平方根。

```cpp
r = r_baseline * 0.5;
r = r_baseline * 1.0;
r = r_baseline * 2.0;
```

观察：

- R 太小：滤波结果容易受到检测框抖动影响。
- R 合适：能够平衡预测和测量。
- R 太大：滤波结果可能明显落后于实际目标。

### 第四步：调整模型特有参数

不同模型的特殊参数：

- CT-EKF5D：q_alpha。
- CT-EKF6D：q_alpha、init_omega_var、init_alpha_var。
- GeneralMotionEKF6D：q_omega、init_heading_var。
- SingerKF6D：tau。

一次只调整一个参数，避免无法判断究竟是哪一个参数改善了效果。

### 第五步：调整初始协方差

只有当模型刚创建时的运动估计明显不稳定，才需要重点调整初始方差。

例如：

- 初始速度估计不准确：调整 init_velocity_var 或 init_speed_var。
- 初始角速度估计不准确：调整 init_omega_var。
- 初始加速度估计不准确：调整 init_alpha_var 或 init_accel_var。
- 初始运动方向不准确：调整 init_heading_var。

初始方差增大意味着滤波器对初始化状态更不确定，会更容易接受后续测量修正。

## 11. 常见问题与调参方向

| 实际问题 | 优先考虑的参数 |
|---|---|
| 滤波框明显落后于目标 | 增大 Q 或减小 R |
| 滤波框跟着 YOLO 抖动 | 减小 Q 或增大 R |
| 目标加速时预测跟不上 | 增大 q_accel 或相应的 q |
| 目标转弯时预测跟不上 | 增大 q_alpha 或 q_omega |
| 转弯过程中轨迹不稳定 | 减小角运动过程噪声 |
| 加速度持续时间过长 | 减小 Singer tau |
| 加速度消失得太快 | 增大 Singer tau |
| 刚创建 Track 时预测偏差很大 | 检查初始化点和初始协方差 |
| 连续漏检后预测快速偏离 | 检查运动模型是否符合实际轨迹，并调整过程噪声 |

需要注意：增大 Q 并不一定能解决所有预测偏移问题。如果实际运动模型与滤波器假设差异太大，应考虑更换模型，而不是无限增大 Q。

## 12. 多目标跟踪项目的实验建议

当前示例默认使用 CT-EKF5D。YOLO 与轮廓校正共用一套位置测量噪声。更换测量来源后，重新估计中心误差。

建议选取同一段视频，分别运行不同滤波器。

### 12.1 测试场景

建议至少包含以下四种：

1. 目标匀速运动。
2. 目标加速和减速。
3. 目标连续改变运动方向。
4. YOLO 连续漏检，依靠预测维持跟踪。

### 12.2 记录的数据

建议每个模型记录：

| 指标 | 含义 |
|---|---|
| 中心预测误差 | 预测中心与真实中心的距离 |
| 1帧预测误差 | 预测下一帧的位置误差 |
| 3帧预测误差 | 连续漏检3帧后的预测误差 |
| 5帧预测误差 | 连续漏检5帧后的预测误差 |
| 中心抖动 | 滤波后中心位移的波动程度 |
| 恢复时间 | YOLO 重新出现后恢复正确关联所需帧数 |
| 错误关联次数 | 是否关联到了其他目标 |

预测误差可用人工标注中心计算。评估 3 帧、5 帧无观测预测时，可直接在已初始化的滤波器上依次调用 `predict()`，或为实验临时提高管理器的轨迹保留上限。默认示例连续两帧未匹配就会删除轨迹。

### 12.3 最终模型选择

可以按照实际表现进行选择：

- 匀速运动效果最好：优先考虑 CV-KF。
- 加速度相对稳定：优先考虑 CA-KF。
- 加速度会逐渐衰减：考虑 Singer-KF。
- 运动以协调转弯为主：考虑 CoordinatedTurnEKF5D。
- 转弯速度变化明显：考虑 CoordinatedTurnEKF6D。
- 速度大小和运动方向都会变化：考虑 GeneralMotionEKF6D。

不要单纯根据模型复杂程度选择。状态维度更高不代表预测一定更准确。
